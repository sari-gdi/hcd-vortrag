# HCD-Vortrag

Interaktiver Inhouse-Vortrag zur menschzentrierten Gestaltung (Human-Centred Design) nach ISO 9241-210 und CPUX-F Curriculum (UXQB e.V., 2023).

Eine scrollbare HTML-Seite, die in rund zehn Minuten die Begriffe UI, UX und HCD voneinander abgrenzt, den Prozess nach ISO 9241-210 erläutert, drei zentrale Methoden zeigt und den Beitrag verschiedener Rollen im Team beschreibt. Mit klickbarem Akkordion, anklickbarem Prozesskreis, Methodenkarten zum Aufdecken und einem Mini-Game zu typischen Usability-Problemen.

## Aufbau

```
index.html            Markup, in 7 nummerierte Sektionen aufgeteilt
style.css             Stylesheet mit GD-Tokens (Hind, Archiv Grotesk, Helm-Neon)
script.js             Behavior: Akkordion, Kreislauf, Karten, Mini-Game, Rollenmatrix, Progress
hcd-blogartikel.md    Begleitartikel fuer die Wissenswelt
```

## Lokal oeffnen

`index.html` im Browser oeffnen. Keine Build-Pipeline, kein Server noetig.

Die Schrift "Archiv Grotesk" ist lokal beim Sprecher installiert. Fuer andere Endgeraete greift "Archivo" als Web-Fallback aus Google Fonts.

## Inhalt

- 01 Hero — Einleitung, statische Prozessgrafik
- 02 UI · UX · HCD — Akkordion mit Definitionen aus dem CPUX-F
- 03 Der HCD-Prozess — vier Aktivitaeten nach ISO 9241-210, Iterationen, Exit-Bedingung
- 04 Methoden — Persona, User Journey Map, Usability-Test
- 05 Uebung — sechs typische Usability-Probleme im Formular finden
- 06 Beitrag der Rollen — PM, Entwicklung, Design, HR, Backoffice, Sales
- 07 Zum Mitnehmen — fuenf Kernpunkte
